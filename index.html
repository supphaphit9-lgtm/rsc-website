ROYAL SECURITY COMMAND

หน่วยงานราชการในพระองค์ที่มีเกียรติยศสูงสุด ปฏิบัติภารกิจการถวายความปลอดภัย ถวายอารักขา ถวายพระเกียรติ แด่องค์พระมหากษัตริย์ พระราชินี และพระบรมวงศานุวงศ์ ด้วยความจงรักภักดีและวินัยอันเข้มงวดสูงสุด

ศึกษาประวัติหน่วย โครงสร้างการบริหาร
HISTORY & ORIGIN

ประวัติความเป็นมาและวิวัฒนาการ

ตราสัญลักษณ์ประจำหน่วย นถปภ.รอ.

ต้นกำเนิดและวิวัฒนาการแห่งเกียรติยศ

การถวายความปลอดภัยและการถวายอารักขาแด่องค์พระมหากษัตริย์และพระบรมวงศานุวงศ์ ถือเป็นภารกิจที่มีความสำคัญสูงสุดและมีประวัติศาสตร์สืบทอดมาอย่างยาวนานนับตั้งแต่อดีต เดิมทีภารกิจอันทรงเกียรตินี้กระจายอยู่ในความดูแลของหลายหน่วยงาน เช่น กรมราชทหารเสือ กรมราชหัตถเลขา และกองตำรวจราชสำนัก

ต่อมาเพื่อให้การปฏิบัติงานด้านการถวายความปลอดภัย การรักษาความสงบเรียบร้อยภายในพระราชฐาน และการจัดพระราชพิธีถวายพระเกียรติ มีความเป็นเอกภาพ มีความรวดเร็ว และมีประสิทธิภาพสูงสุดตามมาตรฐานยุทธวิธีระดับสากล จึงได้มีการยกระดับและจัดตั้ง **"หน่วยบัญชาการถวายความปลอดภัยรักษาพระองค์" (Royal Security Command)** ขึ้นเป็นส่วนราชการในพระองค์โดยตรง

หน่วยงานนี้ยึดถือระเบียบ วินัย และหลักยุทธวิธีอันเคร่งครัด เจ้าหน้าที่ทุกคนผ่านการคัดเลือกและการฝึกอบรมอย่างเข้มข้น ทั้งในด้านการยิงปืนยุทธวิธี การถวายอารักขาบุคคลสำคัญ (VVIP Protection) การอารักขาขบวนเสด็จ และการต่อต้านการก่อการร้าย เพื่อทำหน้าที่เป็นเกราะแก้วปกป้องสถาบันพระมหากษัตริย์ด้วยชีวิต

ยุคก่อตั้ง

การรวบรวมกำลังพลถวายอารักขา

เริ่มต้นจากการจัดตั้งกองกำลังทหารมหาดเล็กและกำลังพลคัดสรรพิเศษ เพื่อดูแลความปลอดภัยรอบเขตพระราชฐานชั้นในและชั้นนอก

การยกระดับ

สถาปนาโครงสร้าง นถปภ.รอ.

ปรับปรุงโครงสร้างการบริหารงานใหม่ รวมหน่วยปฏิบัติการพิเศษ กรมราชโองการ และกองทหารมหาดเล็กฯ เข้าด้วยกันอย่างเป็นระบบ

ปัจจุบัน

มาตรฐานยุทธวิธีระดับสูง

พร้อมปฏิบัติภารกิจถวายความปลอดภัย 24 ชั่วโมง ด้วยเทคโนโลยี อุปกรณ์ทันสมัย และระบบควบคุมสั่งการที่แม่นยำ

ORGANIZATION STRUCTURE

โครงสร้างและหน่วยงานในสังกัด

แบ่งส่วนราชการเพื่อการควบคุม สั่งการ และปฏิบัติภารกิจได้อย่างมีประสิทธิภาพสูงสุด

กองบัญชาการทหารมหาดเล็กราชวัลลภรักษาพระองค์

ทม.รอ. / King's Guard

รับผิดชอบการจัดตั้งกองทหารเกียรติยศ การตั้งแถวรับเสด็จ การรักษาการณ์ ณ พระบรมมหาราชวัง และพระราชฐานทั่วประเทศ

สายงาน: ปฏิบัติการภาคสนาม

สำนักงานนายทหารปฏิบัติการพิเศษ

นปพ.รอ. / Special Ops

หน่วยปฏิบัติการอารักขาระยะชิด (Close Protection) การวางกำลังต่อต้านซุ่มยิง และชุดเคลื่อนที่เร็วถวายความปลอดภัย

สายงาน: ยุทธวิธีพิเศษ

กรมราชโองการ

Royal Command Dept.

ดูแลงานหนังสือราชการ งานพระราชพิธี พิธีการ กฎระเบียบ ข้อบังคับ และการประสานงานส่วนราชการในพระองค์

สายงาน: บริหารและสารบรรณ

กองอำนวยการถวายความปลอดภัย

กอ.ถปภ. / Security Ops Center

ศูนย์สั่งการข่าวกรอง วางแผนยุทธศาสตร์เส้นทางเสด็จ ประสานงานกองทัพและตำรวจเพื่อเคลียร์พื้นที่ยุทธศาสตร์

สายงาน: ข่าวกรองและวางแผน
PRIMARY MISSIONS

ภารกิจหลักแห่งเกียรติยศ

การถวายความปลอดภัยขั้นสูงสุด

วางแผน วางกำลัง และถวายการอารักขาแด่องค์พระมหากษัตริย์ พระราชินี พระรัชทายาท และพระบรมวงศานุวงศ์ ตลอด 24 ชั่วโมง ทั้งในและนอกพื้นที่

การถวายพระเกียรติในงานพิธี

จัดตั้งกองทหารเกียรติยศ นำขบวนเสด็จ และดำเนินการในพระราชพิธีสำคัญต่างๆ ให้เป็นไปตามราชประเพณีอันสง่างามและสมพระเกียรติ

การรักษาการณ์พระราชฐาน

ควบคุม ตรวจสอบ และรักษาความปลอดภัยอย่างเข้มงวด ณ เขตพระราชฐาน พระตำหนัก และสถานที่สำคัญทางยุทธศาสตร์

การยิงปืนยุทธวิธีและอารักขา

ฝึกซ้อมทักษะการใช้อาวุธ การยิงปืนฉับพลัน การขับรถอารักขาขบวนเสด็จ และเทคนิคต่อต้านซุ่มยิงอย่างสม่ำเสมอ

การข่าวกรองและความอุตสาหะ

สืบสวน ประเมินสถานการณ์ความเสี่ยง ค้นหาสิ่งผิดปกติและป้องกันภัยคุกคามล่วงหน้าก่อนเกิดเหตุการณ์ทุกรูปแบบ

การฝึกอบรมวินัยและระเบียบ

ธำรงไว้ซึ่งระเบียบวินัยทหารอย่างสูงสุด ฝึกฝนร่างกาย และสร้างสรรค์บุคลากรที่มีความจงรักภักดีอย่างแท้จริง
